# TaskFlow – Python To-Do List & Calendar Manager

A professional task management web application built using Python and Flask. TaskFlow helps users organize their daily activities, manage tasks, and plan their schedules through a clean and user-friendly interface.

## 🚀 Features

- Add new tasks.
- View your task list.
- Mark tasks as completed.
- Undo completed tasks.
- Delete tasks.
- Calendar-based task organization.
- Professional and responsive user interface.
- Store tasks using SQLite database.

## 🛠️ Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework
- **HTML** – Web page structure
- **CSS** – Styling and design
- **SQLite** – Database management
- **Jinja2** – HTML templating



## 🎯 Project Objective

The main objective of TaskFlow is to provide a simple and efficient platform for managing daily tasks and improving productivity through organized task tracking and calendar-based planning.
